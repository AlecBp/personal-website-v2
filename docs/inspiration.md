## Patterns that fit Alec

1. **First sentence is the headline.** "Alec Pagliarussi likes building things." set big; no separate tagline block.
2. **One huge jump in type size.** One display line, then 16–18px for everything else. No mid-sized clutter.
3. **One accent, used sparingly** — on the name, a dot, or link underlines.
4. **Portrait part of the grid:** small and square in a gutter, or tinted into the palette. Not a circular avatar, not a hero photo. Optional plain caption (swyx).
5. **Route as a quiet year list,** oldest first so it reads as a journey, ending in an open "2026 →" row ("new challenges, bigger projects"). Life rows (teaching, the print shop) sit in the same list.
6. **Hobbies and contact as sentences** with inline links, skiing and camping first.
7. **Speech-like lines** carry personality ("The teacher in me never really left.").
8. **Optional:** a dated "Now" block (only if it will be kept current); a one-line colophon.

## Avoid

- Chrome pretending to be personality: carousels, cursor effects, version numbers, animated heroes.
- Homepage as a blog index; pill buttons, social-icon rows, centred avatar-and-bio stacks.
- Diary tone and personal-life detail. An undated /now.
